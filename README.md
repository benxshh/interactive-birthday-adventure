# Interactive Birthday Adventure 🎮✨

A pixel-art-inspired interactive website built with HTML, CSS, and JavaScript. This project combines creative web design with interactive features to create a small, game-like experience.

## 🌐 Live Demo

**[Play the Interactive Birthday Adventure](https://benxshh.github.io/interactive-birthday-adventure/)**

## ✨ Features

- **Interactive Mini-Game:** Complete a quest by collecting three stars.
- **Unlockable Birthday Letter:** Discover a personalized letter after completing the game.
- **Make a Wish:** An interactive wish form with a custom response.
- **Secret Room:** Unlock a hidden area using a password.
- **Random Title Generator:** Generate fun, randomized titles.
- **Animations and Effects:** Smooth transitions, floating sparkles, and a shooting-star effect.
- **Final Birthday Surprise:** Discover a special ending after progressing through the experience.
- **YouTube Music Embed:** Listen to a song within the website.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/benxshh/interactive-birthday-adventure.git
   ```

2. Open the project folder in Visual Studio Code.

3. Start a local server:

   ```bash
   python -m http.server 8000
   ```

4. Open `http://localhost:8000` in your browser.
